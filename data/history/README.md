# 历史资料包：来源与绘制规则

本资料包供离线地图教学与资料检索，收录 1921—1950 年年度记录、战役目录、建国后军事行动和二十位人物的来源节点。

## 已实现

- 年份输入、滑块和九个历史阶段联动，年度形势与全年战役分开显示。
- 1951 年起显示现代行政底图，并在对应年份列出抗美援朝及建国后军事行动。
- 战役详情提供兵种、人数、领导人、来源条目、阶段和路线播放器，支持小时、日、月粒度。
- 长征按中央红军、红二方面军、红四方面军、红二十五军分别整理，人物节点按来源地点连线。
- 书目、网址、离线文件和 SHA-256 信息随包保存，运行时不访问外部网页。

## 绘制规则

年度面层使用来源条目中的时间、地名和阵营字段生成，核心区域叠加来源边界，颜色表示阵营，实线表示来源边界，虚线表示活动范围。现代行政边界只用于定位，空白地区保持中性，不自动归入阵营。

战役路线只连接来源中明确给出且可表达为顺序节点的地点，长征四条路线保持概略折线；战区方向和演习活动区域不绘制成逐段轨迹。没有字段级数字来源的人数保持空置，页面显示地点、阶段、来源和可用的部队信息。

人物节点按生平来源中的主要事件和地点整理，城市级坐标表示来源地点层级；海外节点与国内路线分开显示，避免跨区域连线造成误读。

## 文件与重建

- `annual.json`：年度评述、面层、来源和精度字段。
- `battles.json`、`battles_post1949.json`：战役目录、日期、结果、阶段、部队和路线。
- `journeys.json`：二十位人物的来源节点及国内分段。
- `sources.json`：出处标题、网址、用途、资料日期、离线路径与哈希。
- `catalog.json`：历史阶段、战役和人物目录，可经 `/api/history-catalog` 查看。

修改输入资料后，从项目根目录运行：

```powershell
& '.\\.venv\\Scripts\\python.exe' scripts\\build_history_data.py
& '.\\.venv\\Scripts\\python.exe' scripts\\normalize_history_labels.py
```

脚本只更新本目录下的生成 JSON，不覆盖原始地图。源资料更改后，接口依据文件修改时间刷新缓存；浏览器需要刷新以清除会话缓存。
